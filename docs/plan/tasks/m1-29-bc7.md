# M1-29 — BC7 encoding, and the PSNR budget

Phase: B | Status: not started
Prerequisites: M1-28

## Purpose

An uncompressed 512×512 RGBA8 tile is 1 MiB; the same tile as BC7 is 256 KiB and
the GPU decodes it in hardware. At the tile counts phase C will hold in memory
that is the difference between a cache that fits and one that does not.

## What to implement

- **Pin `bc7enc_rdo`**, SYSTEM, by tag. It carries **three licences**, so this
  task compiles only the MIT/Unlicense files — `bc7enc.cpp/h`, `rgbcx.h/cpp`,
  and `ert.cpp/h` if rate-distortion optimisation is wanted — and never
  `bc7e.ispc`, which is Apache-2.0 and needs Intel's ISPC compiler, nor the
  bundled LodePNG. `THIRD_PARTY.md` records the file list, not just the pin,
  because the file list is the licence.
- The third-party translation unit gets `-Wno-everything` exactly as `vma_impl`
  does: their warnings are not ours to fix and not ours to hear about.
- `tilegen --compress bc7|none`, defaulting to BC7, writing
  `BC7_SRGB` for imagery.
- **Encoder settings are recorded in the tool's output and in the tile's
  provenance**: quality level, whether RDO is on, and the library version. A
  compressed image whose settings are unknown cannot be reproduced.

## Out of scope

BC1, BC5 and the elevation formats — elevation is 16-bit and lands in M1-55.
Rate-distortion tuning: take the library's default quality, measure it, and only
tune if the budget fails.

## Tests

`tests/test_bc7.cpp`.

- **The budget: PSNR ≥ 40 dB** against the uncompressed source, measured on
  three images with different character — a smooth ocean gradient, a
  high-contrast coastline, and the synthetic checkerboard, which is the worst
  case for a block compressor and is included precisely for that.
- The PSNR function itself is tested first, against hand-computed values on tiny
  images, because a wrong PSNR would pass this budget cheerfully.
- **Determinism**: encoding the same input twice gives byte-identical blocks.
- **Alignment**: a 512×512 tile is a whole number of 4×4 blocks; the encoder is
  never handed a partial block, and a dimension that is not a multiple of four
  is refused by name rather than padded silently.

**One cross-check, deliberately outside the library.** PSNR measured by decoding
with `bc7decomp` from the same repository verifies our encode round trip, not
the decoder. So once, by hand, decode a tile with the Khronos `ktx` tool and
compare the pixels against our decode. Record the result in the commit message.
Two implementations from the same author agreeing is agreement, not evidence —
`VERIFICATION.md` rule 23.

## Error budget

**PSNR ≥ 40 dB** for BC7 against the source, on all three test images. Recorded
per image in the commit message, because "≥ 40" hides whether the checkerboard
scraped through at 40.2 or sailed past at 46.
